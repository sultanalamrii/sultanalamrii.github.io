غير متصل
ما عندك مفتاح أو ضاع؟ اضغط الزر، وتفتح صفحة GitHub وكل شيء معبأ (صلاحية دائمة بلا انتهاء).
🔑 إنشاء مفتاح جديد
خطوات إنشاء المفتاح (دقيقة واحدة)
  1. اضغط زر «إنشاء مفتاح جديد» وسجّل دخولك في GitHub إن طُلب.
  2. الاسم والمدة (No expiration) والصلاحية (Contents: Read and write) معبأة تلقائياً.
  3. في Repository access اختر Only select repositories ثم اختر maktaba.
  4. اضغط Generate token في الأسفل، وانسخ المفتاح (يبدأ بـ github_pat_).
  5. ارجع هنا، والصقه في الخانة، واضغط «حفظ والاتصال».
المفتاح يبقى محفوظاً في هذا المتصفح، فلا تحتاجه مرة ثانية إلا إذا غيّرت الجهاز أو المتصفح أو مسحت بياناته. وإن ضاع، اصنع مفتاحاً جديداً بنفس الزر واحذف القديم من GitHub.
