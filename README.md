# مكتبة الكتب — دليل مختصر

## إضافة كتاب (لصاحب المكتبة)
1. افتح صفحة الإدارة: `رابط-الموقع/admin.html`
2. أول مرة فقط: الصق مفتاح GitHub واضغط «حفظ والاتصال».
3. اكتب اسم الكتاب، واختر التصنيف والغلاف وملف PDF، ثم اضغط «نشر الكتاب».
4. يظهر الكتاب في الموقع خلال دقيقة إلى ثلاث دقائق.

من نفس الصفحة: تعديل الاسم، تغيير الغلاف، الترتيب، الحذف، التصنيف، وإعدادات الموقع.

## ملاحظات
- صفحة الإدارة تقبل ملفات حتى 95 ميجابايت، أما الرفع من متصفح GitHub فحدّه 25 ميجابايت.
- إذا ظهرت رسالة «انتهت صلاحية المفتاح»: اضغط زر «إنشاء مفتاح جديد» في صفحة الإدارة.
- لا يحتاج الموقع أي تحديثات أو صيانة، وكل المكتبات والخطوط محفوظة داخله.

## الهوية اللونية لكل عميل
- من صفحة الإدارة ← إعدادات الموقع ← «الهوية اللونية»: اختر هوية جاهزة (زمردي، كحلي، عنّابي، بنّي قهوة، فيروزي، فحمي وبرتقالي) أو حدّد 4 ألوان (الأساسي، المميز، الخلفية، النصوص) ولوناً مساعداً اختيارياً لسطر المؤلف، ثم «حفظ الإعدادات».
- أو يدوياً في books.json داخل "site":
  `"theme": { "primary": "#1E3A5F", "accent": "#C9A45C", "bg": "#F5F3EE", "ink": "#1F2933" }`
- باقي الدرجات (الغامق والفاتح والحدود والظلال وألوان القارئ والأيقونة) تُشتق تلقائياً، مع ضمان وضوح النص العربي.
- بدون "theme" تبقى الهوية الافتراضية (الزمردي) كما هي تماماً.
- بعد تغيير الهوية أعد تشغيل `python3 tools/configure.py رابط-الموقع` لتتلوّن صورة المشاركة (og.jpg) بنفس الهوية.
- لا تعدّل الألوان داخل ملفات CSS؛ كل الألوان متغيرات تبدأ بـ --t- في قسم «الهوية اللونية» آخر assets/style.css.

## الظهور في محركات البحث (v37)
- لكل كتاب صفحة نصية في مجلد `kitab/` يقرأها Google ونماذج الذكاء الاصطناعي، وفيها رابط «اقرأ الكتاب».
- قائمة الكتب الثابتة داخل `<noscript>` في `index.html` (بين علامتي SEO)، و `sitemap.xml` و `llms.txt` في جذر الموقع.
- كل هذا يتحدث تلقائياً: مع أي تغيير في `books.json` أو مجلد `books` يشتغل «تحديث صفحات محركات البحث» (`.github/workflows/seo.yml`) ويشغّل `tools/build_seo.py`. ما يحتاج تعديل يدوي.
- ملف التحقق من Google (`google….html`) في جذر المستودع **لا يُحذف ولا يُعدّل**.
